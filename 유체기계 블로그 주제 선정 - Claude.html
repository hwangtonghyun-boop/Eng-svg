Engineering-Lab에서 다루기 좋은 유체기계 주제를 검색 수요와 실무 깊이를 기준으로 골라봤습니다. 이미 펌프 위주로 30편 정도 쌓여 있으니, 펌프를 더 깊게 파는 글과 압축기·송풍기·터빈으로 범위를 넓히는 글을 섞었습니다.

펌프 심화 (기존 독자층 유지)

  1. NPSHa vs NPSHr, 왜 3% 수두강하 기준일까? 캐비테이션 판정 기준의 의미와 마진(API 610 권장치) 설정법 — npsh-margin.html
  2. 펌프 성능곡선 읽는 법: BEP, POR, AOR 구간 운전점이 BEP에서 벗어날 때 생기는 진동·재순환 문제 — pump-curve-bep.html
  3. 비속도(Ns)와 흡입비속도(Nss)로 임펠러 형상 예측하기 계산 예시 포함 — specific-speed.html
  4. 최소유량(Minimum Flow)과 재순환 라인 설계 실무에서 자주 놓치는 포인트 — minimum-flow-recirculation.html
  5. API 610 성능시험 허용오차 정리 양정·유량·효율·NPSH 판정 기준 (본인 실무 경험을 녹이기 좋은 주제) — api610-performance-test.html

범위 확장 (신규 유입용)
6. 원심 압축기 서징(Surge)과 초크(Choke) 안티서지 제어 원리까지 — compressor-surge.html
7. 송풍기 vs 블로워 vs 압축기, 압력비로 구분하기 입문자 검색 수요가 꾸준한 비교형 주제 — fan-blower-compressor.html
8. 상사법칙(Affinity Laws)과 VFD 에너지 절감 회전수 변경 시 유량·양정·동력 변화 계산 — affinity-laws-vfd.html
9. 수격현상(Water Hammer) 원인과 방지 대책 체크밸브 선정과 연결 가능 — water-hammer.html
10. 용적식 펌프(기어·스크류·다이어프램) 선정 가이드 원심펌프와 비교 — positive-displacement-pump.html

색인 문제를 감안하면 1, 6, 8, 9번처럼 일반 검색량이 있는 키워드 글을 먼저 올려 신호를 만들고, 5번처럼 전문성이 높은 글은 내부 링크로 엮는 순서가 유리해 보입니다. 이 중 하나 골라주시면 SVG 도식 구성안과 함께 본문 초안 잡아드릴게요.

"펌프 성능곡선 읽는 법 – BEP, POR, AOR 구간이 의미하는 것" 글을 Blogger에 바로 붙여 넣을 수 있는 HTML로 완성했습니다. 퍼머링크는 pump-curve-bep을 권장하고, 파일 맨 위 주석에 메타 설명과 라벨도 넣어 두었습니다. 본문은 성능곡선 기본, BEP와 반경하중의 관계, 축동력 계산 예시, API 610 기준 POR(BEP 유량의 70~120%, 정격점은 80~110%)과 AOR, 저유량·고유량 쪽에서 생기는 문제, 선정할 때 확인할 체크포인트 순서로 구성했습니다.

올리기 전에 손볼 곳 두 군데

  1. 도식 주소 교체: pump-curve-bep.svg를 GitHub에 올린 뒤, HTML 안의 USERNAME/REPO 부분을 실제 경로로 바꿔 주세요.
  2. 경험 사례 넣기: 본문 중간에 회색 박스로 비워 둔 자리가 있습니다. 여기에 직접 겪은 사례를 한두 문단 넣으면 됩니다. 예를 들어 성능시험에서 AOR 경계 근처의 진동값이 어떻게 변했는지 같은 내용입니다. 이런 실무 경험이 들어가야 글의 무게가 확실히 달라집니다.
